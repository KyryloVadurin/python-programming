    МЕТОДИЧНІ ВКАЗІВКИ ЩОДО САМОСТІЙНОЇ РОБОТИ
    З ОСВІТНЬОГО КОМПОНЕНТА
    «Програмування на Python. Базовий рівень»

    ВСТУП

    Самостійна робота здобувачів вищої освіти є провідною формою навчальної діяльності у системі вищої технічної освіти, яка забезпечує поглиблене засвоєння теоретичного базису, формування системного інженерного мислення та набуття практичних навичок проєктування сучасного програмного забезпечення. У контексті підготовки бакалаврів за спеціальністю F7 «Комп'ютерна інженерія» освітній компонент «Програмування на Python. Базовий рівень» формує комплекс фундаментальних та прикладних компетентностей, необхідних для розробки системних утиліт, засобів автоматизації інфраструктури, моделювання цифрових пристроїв та обробки телеметричних потоків даних.

    Навчально-методичне забезпечення самостійної роботи базується на комплексному використанні підручників, науково-практичних посібників, конспектів лекцій, лабораторних практикумів, публікацій за профілем дисципліни та офіційної технічної документації мови Python (Python Software Foundation). Методичні вказівки визначають чіткий алгоритм позааудиторної навчальної діяльності здобувачів, спрямований на послідовне опрацювання наукової літератури, виконання аналітичних розрахунків, підготовку до лабораторних досліджень та реалізацію індивідуального завдання у формі розрахунково-графічної роботи (РГР).

    Опрацювання навчального матеріалу після аудиторних занять повинно здійснюватися систематично відповідно до календарно-тематичного графіка навчального процесу. Здобувачам рекомендується після кожної лекції повторити відповідний теоретичний блок, виконати самостійне тестування базових концепцій у середовищі Visual Studio Code, законспектувати ключові моделі та алгоритмічні структури, а також підготувати відповіді на контрольні запитання для самоперевірки. За виникнення теоретичних або практичних труднощів здобувачі мають змогу отримати індивідуальні консультації викладачів кафедри згідно із затвердженим графіком.

    Предметом вивчення освітнього компонента є синтаксичні конструкції, об'єктна модель пам'яті, системна модульна архітектура, механізми забезпечення надійності та парадигми процедурного, функціонального й об'єктно-орієнтованого програмування на базі мови Python 3.10+. Метою викладання компонента є формування стійких практичних умінь та знань щодо проєктування надійних, модульних і масштабованих програмних засобів для розв'язання прикладних задач комп'ютерної інженерії.

    2. ПЕРЕЛІК ТЕМ І ПИТАНЬ ДЛЯ САМОСТІЙНОГО ОПРАЦЮВАННЯ

    Змістовий модуль 1. Архітектура середовища, скалярні типи та структури керування

    Тема 1. Архітектура мови Python, інфраструктура розробника та модель скалярних даних (8 год СР)

    Теми для самостійного опрацювання:

    1. Дослідження внутрішньої організації віртуальної машини CPython, механізмів компіляції вихідного коду в проміжний байт-код та формату зберігання серіалізованих файлів у директоріях __pycache__.

    2. Вивчення архітектурного призначення та системних наслідків глобального блокування інтерпретатора (Global Interpreter Lock, GIL) для багатопотокових процесів у багатоядерних процесорних системах.

    3. Опанування методів створення, активації та експорту конфігурацій віртуальних ізольованих середовищ засобами менеджерів conda та venv.

    4. Вивчення розширених команд системи контролю версій Git щодо розгалуження кодової бази (branch), злиття гілок (merge), розв'язання конфліктів та оформлення pull requests на платформі GitHub. Налаштування лінтерів flake8 та статичного аналізатора mypy у VS Code.

    5. Аналіз об'єктної моделі пам'яті CPython, структури заголовка PyObject, механізму підрахунку посилань ob_refcnt та роботи системного збирача сміття (Garbage Collector).

    6. Дослідження механізму кешування пулу малих цілих чисел у закритому діапазоні \([-5, 256]\) та виділення пам'яті під об'єкти довгої арифметики PyLongObject.

    7. Практичне застосування побітових операцій для моделювання апаратних регістрів мікроконтролерів, накладання бітових масок та вилучення окремих розрядів.

    Питання для самоперевірки:

    1. Які системні кроки виконує інтерпретатор CPython від моменту зчитування файлу з вихідним кодом .py до виконання інструкцій віртуальною машиною PVM?

    2. Чому наявність GIL унеможливлює паралельне завантаження кількох процесорних ядер потоками одного процесу при виконанні обчислювально-складних задач (CPU-bound)?

    3. У чому полягає фундаментальна різниця між концепцією змінної у мовах зі статичною типізацією (C/C++) та моделлю «змінна як іменоване посилання на об'єкт» у Python?

    4. Чому оператор перевірки тотожності a is b повертає True для значення \(256\) і False для значення \(257\), якщо ці змінні ініціалізовані в інтерактивній консолі незалежно?

    5. Які особливості двійкового додаткового коду визначають те, що результат виконання операції побітового заперечення ~x для довільного цілого числа строго відповідає виразу \(-(x + 1)\)?

    6. Як налаштувати файл .gitignore для запобігання потраплянню службових артефактів віртуального середовища та файлів кешу байт-коду до публічного репозиторію?

    Література: основна [1, 3, 4]; інформаційні ресурси [1, 2, 3, 4, 5, 6].

    Тема 2. Керування потоком виконання: розгалужені та циклічні алгоритмічні конструкції (8 год СР)

    Теми для самостійного опрацювання:

    1. Вивчення синтаксичних вимог стандарту PEP 8 щодо оформлення відступів у вкладених блоках розгалужень та аналіз системних винятків IndentationError і TabError.

    2. Дослідження математичного апарату короткої схеми обчислення (short-circuit evaluation) складених логічних виразів з операторами and та or.

    3. Опанування синтаксису та інженерних сценаріїв використання тернарного умовного виразу для реалізації кусочно-неперервних функцій та обробки значень за замовчуванням.

    4. Проєктування оптимізованих алгоритмів чисельного інтегрування та пошуку коренів нелінійних рівнянь за допомогою циклу while, аналіз умов збіжності та механізмів запобігання зацикленню.

    5. Вивчення низькорівневого протоколу ітератора, на якому базується функціонування циклу for, та аналіз ролі службового винятку StopIteration.

    6. Аналіз просторової та часової складності генератора числових діапазонів range() та доведення константності його споживання пам'яті \(O(1)\).

    7. Застосування специфічного блоку else у циклічних конструкціях for та while для побудови оптимізованих алгоритмів лінійного пошуку в масивах даних. Дослідження поведінки break та continue у багаторівневих циклах.

    Питання для самоперевірки:
