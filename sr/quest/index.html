    22. Що відбувається під час виконання операції запису inst.attr = 10, якщо attr спочатку було оголошено як атрибут класу?

    • А) У словнику inst.__dict__ створюється новий локальний ключ attr, який затінює атрибут класу для цього екземпляра

    • Б) Значення attr змінюється у словнику Class.__dict__ для всіх екземплярів

    • В) Збуджується виняток AttributeError через конфлікт імен

    • Г) Атрибут стає приватним і перейменовується алгоритмом name mangling

    23. До яких наслідків призводить оголошення спільного списку як атрибута класу (Class.shared_list = []) при виклику self.shared_list.append(data) з різних екземплярів?

    • Б) Кожен екземпляр автоматично створює власну ізольовану копію списку

    • В) Збуджується виняток PermissionError

    • Г) Список автоматично заморожується у frozenset

    24. Чи є правильним твердження: «Виконання присвоєння inst.attr = 100 завжди змінює значення однойменного атрибута в словнику Class.__dict__»?

    РОЗДІЛ 4. ІНКАПСУЛЯЦІЯ, PEP 8 ТА NAME MANGLING

    27. Що означає префікс з одного символу підкреслення (_attr) в імені поля згідно з конвенцією PEP 8?

    • А) Атрибут призначений для внутрішнього використання класом та нащадками (непублічний API, захист за домовленістю)

    • Б) Атрибут шифрується на рівні ядра ОС

    • В) Інтерпретатор забороняє будь-який доступ до атрибута ззовні

    • Г) Атрибут є константою, яку не можна переприсвоювати

    28. Який префікс ідентифікатора викликає активацію вбудованого механізму спотворення імен (name mangling)?

    • А) Два або більше провідних підкреслень за наявності не більше одного підкреслення в кінці (__attr)

    • Б) Одне провідне підкреслення (_attr)

    • В) Два підкреслення на початку і два в кінці (__attr__)

    • Г) Префікс private_ перед іменем поля

    29. Як компілятор Python перетворює приватне поле __secret у класі Transceiver?

    • А) _Transceiver__secret

    • Б) __secret_Transceiver

    • В) _private_Transceiver_secret

    • Г) Transceiver.__secret

    30. Яка головна інженерна мета впровадження алгоритму спотворення імен (name mangling) у Python?

    • А) Запобігання колізіям імен атрибутів між базовими та похідними класами при наслідуванні

    • Б) Криптографічний захист чутливих даних від читання зловмисником

    • В) Прискорення доступу до пам'яті через зменшення довжини хеш-ключа

    • Г) Автоматична серіалізація об'єктів у двійковий формат

    31. Чому системні методи на кшталт __init__, __len__ та __add__ виключені з дії алгоритму спотворення імен?

    • А) Щоб віртуальна машина PVM могла поліморфно викликати їх за фіксованими іменами системних C-слотів

    • Б) Тому що вони займають надто багато місця в пам'яті

    • В) Це обмеження версії Python 2, яке залишили для сумісності

    • Г) Тому що dunder-методи можуть оголошуватися лише за межами класів

    32. Чи є правильним твердження: «Механізм name mangling повністю РОЗДІЛує читання приватного поля ззовні класу за будь-яких умов»?

    • А) Правда (True)

    • Б) Неправда (False)

    • Б) Публічний інтерфейс, відкритий для читання та модифікації

    • В) Системний магічний dunder-атрибут протоколів мови Python

    • Г) Приватний атрибут, що підлягає алгоритму спотворення імен (name mangling)

    РОЗДІЛ 5. НАСЛІДУВАННЯ, РОМБ, SUPER() ТА ЛІНЕАРИЗАЦІЯ C3 MRO

    35. У чому полягає «проблема ромба» (diamond problem) при множинному наслідуванні?

    • А) У неоднозначності порядку виклику методів та дублюванні ініціалізації спільного базового предка

    • Б) У неможливості створення більше двох нащадків від одного класу

    • В) У РОЗДІЛуванні роботи збирача сміття через циклічні посилання

    • Г) У забороні використання абстрактних методів у проміжних класах

    36. Яку функцію виконує вбудований проксі-об'єкт super() у мові Python?

    • А) Делегує виклик методу наступному класу згідно з порядком MRO викликаючого екземпляра

    • Б) Завжди викликає метод строго лівого батьківського класу

    • В) Перетворює довільний метод на класовий метод @classmethod

    • Г) Створює ізольовану копію базового класу в пам'яті

    37. Який алгоритм використовується інтерпретатором CPython для розрахунку порядку вирішення методів (MRO)?

    • А) Алгоритм лінеаризації C3 (C3 Linearization)

    • Б) Пошук у глибину (Depth-First Search)

    • В) Пошук у ширину (Breadth-First Search)

    • Г) Алгоритм Дейкстри

    38. Які обов'язкові властивості забезпечує алгоритм лінеаризації C3? (Оберіть усі правильні відповіді)

    • А) Монотонність (порядок предків зберігається для всіх підкласів)

    • Б) Збереження локального порядку слідування батьківських класів

    • В) Випадковий вибір гілки у разі виникнення колізій

    • Г) Обов'язковий дублюючий виклик спільних базових класів

    39. Який виняток генерує Python під час спроби оголосити клас із суперечливою ієрархією наслідування, яку неможливо лінеаризувати?

    • А) TypeError (повідомлення: Cannot create a consistent method resolution order)

    • Б) SyntaxError

    • В) RecursionError

    • Г) NameError

    40. Нехай оголошено класи A, B(A), C(A), D(B, C). Яким буде порядок лінеаризації L(D)?

    • А) [D, B, C, A, object]

    • Б) [D, B, A, C, object]

    • В) [D, C, B, A, object]

    • Г) [D, B, A, object]

    41. До чого призводить жорсткий виклик BaseClass.__init__(self) замість super().__init__() у кооперативному множинному наслідуванні?

    • А) Розриває ланцюжок лінеаризації MRO, що може призвести до пропуску ініціалізації сусідніх гілок або повторних викликів

    • Б) Викликає помилку компіляції байт-коду SyntaxError

    • В) Автоматично РОЗДІЛує доступ до атрибутів екземпляра

    • Г) Знищує об'єкт у пам'яті до завершення роботи функції

    42. Який спеціальний атрибут класу повертає кортеж лінеаризованого порядку дозволу методів?

    • А) __mro__

    • Б) __order__

    • В) __bases__

    • Г) __hierarchy__

    РОЗДІЛ 6. КАЧИНА ТИПІЗАЦІЯ ТА DUNDER-МЕТОДИ

    45. Що є головним критерієм сумісності об'єкта з протоколом в концепції качиної типізації (Duck Typing)?

    • А) Наявність у об'єкта необхідних методів та атрибутів у момент виклику, незалежно від його наслідування

    • Б) Обов'язкова наявність спільного абстрактного предка

    • В) Збіг фізичного розміру структури PyObject у пам'яті

    • Г) Явна попередня реєстрація типу у словнику sys.modules

    46. Яка пара dunder-методів реалізує протокол ітерування в Python?

    • А) __iter__ та __next__

    • Б) __enter__ та __exit__

    • В) __getitem__ та __len__

    • Г) __init__ та __call__

    47. Які методи обов'язково повинен реалізувати клас для підтримки роботи з інструкцією with?

    • Б) __open__ та __close__

    • В) __start__ та __stop__

    • Г) __acquire__ та __release__

    48. Що повинен повернути метод перевантаження оператора __add__(self, other), якщо тип операнда other не підтримується?

    • А) NotImplemented (системну константу, яка сигналізує PVM спробувати викликати __radd__)

    • Б) Згенерувати виняток raise TypeError

    • В) Повернути логічне значення False

    • Г) Повернути об'єкт None

    4. __repr__

    Операції:

    • А) Доступ за індексом або ключем obj[key]

    • Б) Обчислення модуля або евклідової норми abs(obj)

    • Г) Операція перевірки рівності obj == other

    РОЗДІЛ 7. ДЕСКРИПТОРИ, PROPERTY, CLASSMETHOD ТА STATICMETHOD

    51. У чому полягає відмінність між дескриптором даних (data descriptor) та дескриптором без даних (non-data descriptor)?

    • А) Дескриптор даних визначає метод __set__ або __delete__, а дескриптор без даних — тільки __get__

    • Б) Дескриптор даних зберігає числа, а дескриптор без даних — рядки

    • В) Дескриптори даних можуть оголошуватися лише всередині функцій

    • Г) Дескриптори без даних не мають доступу до аргументу instance

    52. Який пріоритет має пошук атрибута, якщо в класі визначено дескриптор даних із методом __set__, а в instance.__dict__ вже існує однойменний ключ?

    • А) Дескриптор даних має вищий пріоритет і викликається раніше за словник екземпляра

    • Б) Словник екземпляра повністю затінює дескриптор даних

    • В) Збуджується виняток AttributeError через колізію

    • Г) Викликається випадковий метод залежно від стану пам'яті

    53. Що створює вбудований декоратор @property в тілі класу?

    • А) Дескриптор даних, що дозволяє звертатися до методів валідації через синтаксис звичайного атрибута

    • Б) Статичну копію функції в модулі

    • В) Приватне поле, захищене алгоритмом name mangling

    • Г) Окремий процес операційної системи для фонових обчислень

    54. Який перший аргумент автоматично отримує метод, декорований @classmethod, під час виклику?

    • А) cls (посилання на сам об'єкт-клас)

    • Б) self (посилання на конкретний екземпляр)

    • В) mro (порядок лінеаризації)

    • Г) None

    55. Як поводиться метод, оформлений за допомогою декоратора @staticmethod?

    • А) Працює як звичайна функція в просторі імен класу, не отримуючи автоматично ні self, ні cls

    • Б) Отримує першим аргументом глобальний словник модуля

    • В) Автоматично РОЗДІЛує потік виконання за допомогою GIL

    • Г) Викликається виключно один раз під час завантаження програми

    56. Яка основна інженерна сфера застосування декоратора @classmethod?

    • А) Створення альтернативних конструкторів (фабричних методів) для різних форматів даних

    • Б) Обчислення контрольних сум бінарних РОЗДІЛів

    • В) Заборона створення екземплярів класу

    • Г) Створення глобальних змінних

    57. Яким чином декларація атрибута __slots__ оптимізує використання пам'яті екземплярами класу?

    • А) Усуває створення словника __dict__, замінюючи його статичним масивом покажчиків фіксованого розміру

    • Б) Автоматично переводить усі змінні у формат float32

    • В) Стискає екземпляр класу за допомогою алгоритму zip

    • Г) Вивантажує невикористовувані поля у файл підкачки

    58. Що станеться, якщо клас-нащадок успадковує клас із __slots__, але сам не оголошує власний атрибут __slots__?

    • А) Екземпляри нащадка отримають стандартний словник __dict__, що нівелює оптимізацію пам'яті для нових полів

    • Б) Інтерпретатор збудить виняток TypeError під час компіляції класу

    • В) Нащадок повністю втратить доступ до полів батьківського класу

    • Г) Нащадок автоматично успадкує фіксовану пам'ять без створення __dict__

    • А) Методи вбудованих С-типів у CPython реалізовані на C і викликають низькорівневі C-функції в обхід методів Python-рівня

    • Б) Тому що метод update() заборонено викликати в класах-нащадках

    • В) Через дію алгоритму name mangling

    • Г) Тому що словники не підтримують поліморфізм

    60. Чи є правильним твердження: «Завдяки наявності Global Interpreter Lock (GIL) у CPython операція інкременту атрибута self.counter += 1 є абсолютно атомарною і потокобезпечною»?
